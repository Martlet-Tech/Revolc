# Revolc 接管事故与修复备忘（2026-11-17，当日已全线打通）

## 最终结论（完整的崩溃链）
1. **GetSite 返回 `Error::empty()`（HRESULT=S_OK）却未写入 ppvsite** → Explorer 读未初始化指针 → 之后 explorerframe.dll 的 COM 同一性比较（+0x4d29a）踩悬空指针 → 79 次崩溃循环（00:29-01:07）。这是全部崩溃的真凶（二分法 V1✓/V2✗/V3✓ + REA 静态分析 explorerframe 定位）。修复：GetSite 返回 E_FAIL。
2. **双实例吸收竞态**：BHO `FindWindowW("RevolcMain")` 把 HWND 送错实例，同窗口被吸收两次；进程被杀时吸收的窗口随宿主销毁。修复：单实例互斥锁。
3. **UIPI 消息拦截**：管理员终端启动的 Revolc 是提权窗口，Explorer（中完整性）的 PostMessageW 被静默丢弃（err=5）。修复：ChangeWindowMessageFilterEx(MSGFLT_ALLOW)。
4. **吸收延迟 1.7s**：吸收前在主线程阻塞 1s 解析路径 + IShellWindows 跨进程枚举 1.5s 重试。修复：SetParent 先行、EnumWindows 进程内发现（15ms）、路径降级为 6×50ms 尽力而为 + 窗口标题兜底。
5. 注册方式：regsvr32 /s 静默吞错 + PowerShell 位数视图重定向，不可靠。用 `reg.exe /reg:64` 直接写注册表并显式 query 验证。

## 系统恢复步骤（有效命令）
管理员 PowerShell：
```powershell
Remove-Item "HKLM:\SOFTWARE\Microsoft\Windows\CurrentVersion\Explorer\Browser Helper Objects\{9F1C4E8B-6A2D-4E7B-8C13-5D04F7A2B916}" -Recurse -Force
```

## 经验
- BHO 是全局注入：进 HKLM 后 Explorer 每个文件夹窗口都会加载，DLL 必须先用 reg.exe /reg:64 显式验证注册完整（BHO 键 + CLSID\InprocServer32 都在）再重启 Explorer。
- COM 服务器 DLL 里每个导出的 HRESULT 都不能想当然：`GetSite` 返回 S_OK 但没写 ppvsite = 给调用方递悬空指针。
- 提权窗口收不到低完整性进程的消息（UIPI）：调试收不到 PostMessage 先查 ChangeWindowMessageFilterEx。
- 崩溃排查入口：事件查看器 Application 日志 Id=1000（模块+offset 聚类）；WER ReportArchive 报告（UTF-16LE Report.wer，log/261117/analyze_wer.py 可批量解析）；`%APPDATA%\revolc\bho.log` 看 SetSite 是否被调用。
- 修 COM/窗口类 bug 时用"最小实现二分法"（V1 空 → V2 加动作 → V3 再裁），每轮一次注册+重启 Explorer 即可定位。
