# Clover 重建目标规格（Rust 版）

> 本文档定义重建目标的行为规格。原版逆向分析见 `clover/Clover_Design_Spec.md`（只作参考，不复制其代码）。
> 本文档刻意精简：未写到的细节由实现者按常识决定，不需要逐条询问。

## 1. 产品定义

一个带多标签页的 Windows 文件管理器外壳：每个标签内嵌**真正的 Explorer Shell 视图**（COM），保留资源管理器的全部原生行为（右键菜单、缩略图、拖拽、地址栏）。

- 不注入任何其他进程
- 不内嵌任何浏览器内核
- 主程序 + 可选更新检查器 + 可选接管监听线程（见 §8），无其他常驻组件

## 2. 平台支持

| 目标 | 要求 |
|---|---|
| OS | Win7 SP1 起步，Win10/11 完整体验，旧系统允许降级 |
| 架构 | x64 + x86 双 target |
| 降级原则 | 特性缺失只影响视觉效果（圆角→直角、透明→纯色、暗色→亮色），不影响功能；用运行时特性检测（GetProcAddress），禁止按 OS 版本号字符串分支 |
| 兼容基础 | manifest 声明全部 supportedOS GUID；x86/x64 双构建在 CI 中编译通过 |

## 3. 核心行为规格

### 3.1 标签页
- 新建 tab（Ctrl+T）：打开新 Explorer 视图，默认路径 = 当前激活 tab 的路径
- 关闭 tab（Ctrl+W / 中键）：销毁该视图；最后一个 tab 关闭时询问是否退出
- 切换：Ctrl+Tab / 点击；悬停自动切换（原版 HoverTabSelector 行为）为可关设置
- 拖拽：tab 拖出后，**落在其他窗口/吸附区上 = 移动或合并到该窗口；落在空白桌面等不可吸附位置 = 落地瞬间创建新实例（新进程）承接该 tab**，此为多实例的主入口（用户不会去双击 exe）；拖拽过程必须有插入位置/落地预览
- tab 上双击空白处 = 新建；tab 上滚轮 = 切换

### 3.2 会话持久化
- 正常退出：保存全部窗口的 tabs（路径、激活态、窗口几何）
- 崩溃恢复：启动时检测上次非正常退出标志，提示"恢复上次会话"
- 启动行为设置项：恢复上次会话 / 打开新 tab / 打开固定路径列表（对应原版 `session.restore_on_startup` 三态）

### 3.3 书签栏
- tab 条下方可选书签栏；书签 = 文件系统路径
- 支持文件夹层级、右键菜单（新建文件夹/重命名/删除/在新 tab 打开）
- 保存格式：JSON（自定 schema，带 version 字段便于迁移）
- 所有配置/会话/书签文件写入必须原子替换（临时文件→flush→rename）

### 3.4 窗口与实例
- 支持单窗口多 tab、**多窗口并存**（典型用法：不同项目各开一个窗口、各一堆 tab）
- 支持多实例运行：**实例通常由 tab 拖拽分离产生**（见 §3.1），也可直接多次启动程序；各实例独立进程、独立会话、互不干涉
- 实例间无父子关系：拖出去就不回头，关闭顺序无所谓，会话各自保存

### 3.5 快捷键
- 所有快捷键集中在一个统一的键位表中定义（按键 → 动作名映射），功能代码只订阅动作名，**禁止在功能实现里散落硬编码按键判断**
- MVP 不做键位绑定设置页，但改配置文件中的键位表即可生效
- 默认键位沿用 §3.1 所列（Ctrl+T/Ctrl+W/Ctrl+Tab 等）

## 4. UI 规格

### 4.0 配置文件
- 用户可自定义的东西全部收敛到**一份配置文件**（TOML，带注释示例）：主题配色、快捷键键位表、启动行为、悬停切换开关等
- **运行时可写、改动立即生效**（文件 watcher 监听 + 热重载），不是"退出程序才生效"或"程序锁住文件"的模式
- 程序自己写配置（设置变更、窗口几何）时也写同一文件；外部手改同样被接受，冲突以后写者为准
- 缺省值内置，配置文件可以从零开始只有两行也能跑

### 4.1 主题
- **运行时可改配色**：改配置文件或后续的设置页均可，立即生效、无需重启
- 主题项至少包含：tab 条背景/前景、tab 激活/非激活色、书签栏配色、字体
- 内置亮/暗两套预设 + 用户自定义

### 4.2 标签页视觉
- 支持透明通道 + 圆角；实现层用分层窗口/自绘，Win7 等不支持的环境自动回退直角纯色
- 圆角半径、tab 高度为主题项

### 4.2.1 Chrome 式一体化标题栏（用户明确要求，高优先）
- tab 条与窗口按钮（最小化 `_` / 最大化 `□` / 关闭 `X`）在同一行，浏览器风格
- 实现方向：去掉系统标题栏（WS_POPUP + 自绘客户区 + WM_NCHITTEST 自定义拖拽/按钮区）
- M0 不做；列入 M4 主题系统范围

### 4.3 布局
- tab 条 + 可选书签栏 + Shell 视图填充剩余区域
- 窗口几何记忆（位置/大小/最大化状态）

## 5. 日志与故障排查

- `tracing` + `tracing-appender`：结构化、文件轮转、组件级过滤（如 `com`、`tabs`、`persist`）
- release 默认 `info` 级，关闭的级别在编译期裁剪，零性能损耗
- 崩溃处理：minidump + 启动时把上次崩溃摘要写入日志头部
- 规范：错误路径必有日志；禁止调试期临时 log 混入提交；禁止 `unwrap()` 出现在 release 代码路径（CI 检查）

## 6. 工程

- 语言：Rust（stable），`windows` crate 作为 Win32/COM 绑定
- UI：纯 Win32 自绘（不用 egui/WebView，理由：需与 Shell COM 子窗口混合且要求 alpha 圆角自绘能力）
- 配置目录：`%APPDATA%\<App>\`（配置、日志、崩溃转储分目录）
- 里程碑（按序交付，每步可运行）：
  - M0：主窗口 + tab 条 + Shell 视图嵌入 + 配置文件热重载骨架（架构成立性验证）
  - M1：会话持久化 + 崩溃恢复
  - M2：书签栏
  - M3：tab 拖拽分窗/合并
  - M4：主题系统（含圆角/透明与降级）
  - M5：安装包（x64+x86）+ 更新检查
  - M6：文件夹打开接管（§7；redirect 默认推荐，associate 为高级可选项）

## 7. 系统文件夹打开接管（可选模块，机制调查见 doc/Takeover_Research.md）

> 目标：复刻 Clover 的核心体验——"系统任何方式打开文件夹，打开的都是本程序"，
> 且开关完全可控、**绝不允许弄坏系统 Explorer 或要求重启**。

### 8.1 设置三态（配置项 `takeover.mode`）

- `off`（默认）：不干预，系统 Explorer 原样工作
- `redirect`：窗口重定向。本程序常驻监听线程（WinEventHook）发现新 Explorer
  文件夹窗口 → 读取路径 → 关闭该窗口 → 以该路径启动本程序新实例。
  零注册表，开关即时生效
- `associate`：用户级注册表关联（`HKCU\Software\Classes\Folder\shell\open\command`）。
  高级选项，默认关闭，实现必须遵守 Takeover_Research.md §3 的六条安全红线
  （只动 HKCU、备份原值、启动自修复、卸载清键、SHChangeNotify 刷新、格式规范）

### 8.2 行为约束

- 只拦截真正的文件夹视图窗口；"此电脑/回收站/控制面板"等不拦
- `redirect` 模式的监听线程随开关启停，不是独立常驻进程
- 接管开关切换不得要求重启 explorer 或电脑
- 本程序崩溃/退出时，系统 Explorer 的任何行为不受影响（红线：接管模块的可失败性
  必须只表现为"不再接管"，绝不表现为"系统打不开文件夹"）

### 7.3 硬验收标准（M6，机制分析见 doc/Takeover_Research.md §3）

浏览器"打开所在文件夹"（`SHOpenFolderAndSelectItems`，不走文件夹关联）必须
调起本程序并选中文件——QTTabBar 类纯关联方案做不到，这是与 Clover 对齐的
核心指标。实现走 WinEventHook 窗口拦截（B1 关旧开新起步，B2 视图吸收升级），
不注入。

## 8. 开放问题：Explorer 工具栏（文件/主页/共享/查看 ribbon）

用户期望保留 Explorer 的 ribbon 命令栏（Clover 有，因为 Clover re-parent 整个
真 Explorer 窗口，ribbon 天然在内）。当前 IExplorerBrowser 嵌入方案只含文件
视图，不含 ribbon。两个候选：

1. 调研 IExplorerBrowser / IShellView 能否显示命令栏（EBO_ 标志 / FWF_ 标志）
2. 若不可行，M6 的 B2 窗口吸收路线天然包含 ribbon——届时"接管后的窗口"即
   完整 Explorer，包括 ribbon；本程序自绘 tab 条 + 吸收真 Explorer 窗口

在 M4 前给出结论。

## 9. 明确不做

- 注入 / hook 其他进程
- 浏览器内核 / 网页渲染
- 遥测上传（启动时可选的版本检查除外，且可关闭）
- 替换系统目录树/面包屑（原版 Clover 的做法，已放弃；接管方式见 §7，只"关旧窗开新窗"，不做运行时 re-parent）
- 机器级注册表劫持（HKCR/HKLM 的 Folder 关联键一律不碰）
